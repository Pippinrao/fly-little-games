# 附近联机当前入口

当前目标：**把已打通的最小可玩路径同步到 Android、HarmonyOS NEXT、iOS，三端均可作为房主/P1 或客机/P2。**

这是现有最小可玩的端侧同步，不是新的 Nearby 产品设计。继续使用三端已有的
“创建联机 / 扫码加入”、大厅、单机游戏页和暂停抽屉；共享 LAN MVP 协议、固定
房主=P1/客机=P2、同 ROM、本地双核心、暂停/继续和回大厅语义不变。既有
Android→Harmony 路径保留同连接换游戏；本次新接方向只用双方已有的首个合格内置游戏，
不顺带扩展导入 ROM 与各端游戏选择器。
不加入好友、六码发现、ROM 传输、自动组网/恢复、STREAM 或新的 UX 流程。

本目录为唯一有效入口；[历史文档](../archive/nearby-2026-09-21/README.md)仅用于追溯。

- [最小可玩设计](DESIGN.md)：热点扫码、真实 DUAL；复用单机页面；暂停、回大厅和换游戏保留连接。
- [执行计划](PLAN.md)：先在两个模拟器修复并验证基本交互，再做必须使用真机的验收。

- [仓库收束记录](REPOSITORY.md)：分支和历史证据的去向。

Android 房主 → HarmonyOS 客机的真实热点和一次摄像头扫码已经连接成功。

当前工作把同一实现接到另外两个平台角色和 iOS，不改变上述产品流程。
