# MMPX independent oracle source notice

The test-only `MmpxCpuOracle` is an independent, direct semantic Java port of the official
MMPX 2x reference implementation by Morgan McGuire and Mara Gagiu. It is intentionally not
shared with the native renderer or GPU shader implementation.

- Paper: *MMPX Style-Preserving Pixel-Art Magnification*, Journal of Computer Graphics
  Techniques, volume 10, number 2, 2021.
- Canonical paper URL: `https://www.jcgt.org/published/0010/02/04/paper.pdf`

## Pixel convention and fixture provenance

Pixels are packed as unsigned `0xAABBGGRR`, matching the little-endian 32-bit view of browser
RGBA image bytes used by the official JavaScript reference. Equality and palette preservation
operate on the complete packed value. Border reads clamp to the nearest source pixel.

The committed fixtures are original, tiny synthetic patterns authored for FlyNES. Their
expected output arrays were generated by executing the unmodified `luma`, equality helpers,
and `runMMPX2X` function extracted from the hash-pinned official JavaScript supplement under
Node.js. No upstream image, ROM image, screenshot, or other art asset is included.

The oracle and fixtures are frozen by
`docs/acceptance/display-quality/mmpx-oracle-manifest.json`. A production renderer must be
compared against the frozen expected arrays; updating the baseline to match production output
is not an acceptable failure resolution.
